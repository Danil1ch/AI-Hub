# AI Hub

Коротко: десктоп-приложение для Windows, где несколько ИИ-сервисов работают в одном окне.

## Что умеет

- Быстрое переключение между сервисами.
- Мультиокно (до 4 панелей).
- Настройки DNS/DoH внутри приложения.
- Сборка portable `.exe` для Windows.

## Что нужно

- Windows 10/11 (x64)
- Node.js 18+ и npm

## Быстрый запуск

```bash
npm install
npm run dev
```

Или двойным кликом по `run-dev.bat`.

## Сборка portable EXE

```bash
npm run dist
```

Готовый файл будет в папке `release/`.
Можно запустить `build-portable.bat`.

## Где что

- Исходники: `src/`
- Готовая dev/build сборка: `out/`
- Релизный `.exe`: `release/`

## Важно

- Проект бесплатный (MIT).
- Сами сервисы внутри могут требовать свои аккаунты/подписки.
